# Dataset

Download the CSV from the [Kaggle Indian stock market dataset](https://www.kaggle.com/datasets/rockyt07/stock-marketsensex-nifty-all-time-dataset) and place it in this folder, or upload it from the Streamlit sidebar.

The application accepts common Date/Open/High/Low/Close/Volume column names and can handle either a combined file or separate index files. The original file is never overwritten.
